Hop glossary

Names from CONTEXT.md. Do not invent synonyms.

Paths

Rules router — hard constraints, phase bar, effort pick (cheapest / Pioneer score / strongest AA).

Trained router — complexity bin + calibrated P(success) per eligible id; cheapest that clears threshold and max_regret.

Learned stub — dark highest-AA module. Not the trained router.

Scorer — the fitted hop head loaded from disk. Live serve does not retrain.

scorer_down — missing/corrupt artifact. Serve rules, no fake confidence.

Promotion gate — eval that must beat rules before production live. This $100 cycle does not run it. Operator TRAINED_PATH=trained ≠ the gate.

Labels

Calibrated P(success) — 0–1 chance this candidate succeeds; live confidence is this value for the winner.

Complexity bin — trivial | standard | hard | frontier. Feature and reason_code, not the pick.

Success gold — measured after actually running a candidate. Missing ≠ 0.

Silver P(success) — teacher’s query-only guess. Regularizer on unobserved cells only.

not_spec_floors — smoke n and dumps below production. Do not promote as Verified.
