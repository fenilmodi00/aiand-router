10 playground demo prompts

Print beside the laptop. Phase + effort drive the ladder — not prompt magic alone.

How to run live

  1. Gateway on rules/shadow: set TRAINED_PATH=shadow (or unset) and restart uvicorn. Local .env often has trained — that path does not show the Flash→Pro→K3 ladder below. Playground’s path toggle does not override server env today.
  2. Open Playground with router/auto selected.
  3. Set Phase and Effort from the row (not Auto).
  4. Paste the prompt → Run.
  5. Point judges at the model chip and/or response header X-Router-Model (also X-Router-Phase, X-Router-Reason).
Verified dry-run (rules, medium/xhigh/max, current catalog): winners collapse to deepseek-v4-flash · deepseek-v4-pro · kimi-k3. Motif / GLM / Qwen rarely win Pioneer score when Flash/Pro are eligible. Labels below = likely under rules. K3 needs effort=max (premium AA floor). With TRAINED_PATH=trained, picks diverge (often Kimi Code or Flash fallback) — fine for Q&A, not for this ladder.
