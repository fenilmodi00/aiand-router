0. Analogy (30 seconds of brain)

Think of the gateway like a CDN edge rule in front of nine backends. Every agent hop hits one URL. The edge decides which backend gets the request.

  • Rules path = hand-written routing policy (hard filters + Pioneer score). Always available.
  • Scorer = a tiny fitted JSON “weights file” loaded at process start — like shipping a dist artifact, not calling an LLM to decide.
  • Shadow = still serve rules, but log what the Scorer would have picked (X-Router-Trained-Would).
  • Trained = operator flips env so the Scorer’s cheapest-above-bar pick is live.

1. What you built (say this first)

aiand/auto is an OpenAI-compatible coding-agent router. Clients send model: router/auto to our FastAPI gateway; we pick an aiand catalog model per step and forward the completion. Dashboard + landing live in Next.js.

Demo path judges expect: :3000/ landing → /routers/auto → /playground → gateway :8000.

2. Where the code is

  1. src/aiand_router/app.py — HTTP: /v1/chat/completions, models, health, replay
  2. src/aiand_router/router.py — rules: hard constraints → phase bar → Pioneer / cheap / max
  3. src/aiand_router/scorer.py — load artifact, featurize, P(success), cheapest-above-bar
  4. src/aiand_router/train.py — offline teacher → gold → fit (opt-in, spends credits)
  5. config/models.yaml — catalog + list prices
  6. web/ — landing, dashboard, playground

Diagram: ARCHITECTURE.md.

3. How we made the Scorer (pipeline you can draw)

  1. Queries — 2000 coding-agent-ish prompts in datasets/train-queries.jsonl
  2. Teacher (silver) — a chat model guesses P(success) per eligible model from the query alone → data/silver.jsonl (regularizer, not truth)
  3. Gold — we actually run candidates through aiand; success is measured (tools/JSON/no escalate) → gold JSONL
  4. Fit — logistic heads + Platt calibration → data/scorer.json (and hard-transfer variants like scorer-hard-logistic.json)
  5. Serve — process loads Scorer once; live hop is features-only, milliseconds

Label on the smoke/hard artifacts: not_spec_floors. That means “good enough to shadow/demo,” not “we cleared SWE-bench Verified promotion.” Say that proudly — judges trust honesty.
