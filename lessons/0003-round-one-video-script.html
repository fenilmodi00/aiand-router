What to emphasize (judges care about these)

  • Real product, not a slide deck — you have a working gateway + UI, not just a concept.
  • Drop-in compatibility — /v1/chat/completions, no new protocol.
  • Observable routing — headers, JSONL log, dashboard inferences table.
  • Cost intelligence — phase-aware picks, effort tiers, savings vs baseline.
  • ML path is architected — shadow → trained flip, scorer fallback to rules.

What NOT to oversell (stay honest)

  • Trained routing is implemented but not yet the live pick — default is shadow (rules serve, ML records what it would have chosen).
  • Benchmark numbers on the landing page are illustrative / Pioneer-shaped — cite measured eval when you have cache data.
  • Don’t invent savings percentages — point at the dashboard’s logged numbers.

Recording checklist

  1. Gateway running: uvicorn aiand_router.app:app --app-dir src --host 127.0.0.1 --port 8000
  2. Web running: cd web && npm run dev
  3. Pre-seed 3–5 playground requests so dashboard isn’t empty
  4. 1080p, zoom browser to 110% so text is readable
  5. Hide bookmarks bar; close unrelated tabs
  6. Record system audio off unless you want typing sounds
