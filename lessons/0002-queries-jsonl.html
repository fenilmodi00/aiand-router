Lesson 0001 · Pipeline card · Glossary · Starter file

You are not training an LLM. You are labeling a JSONL of coding requests.

Frontend analogy: queries.jsonl is a fixtures file. The train CLI is three npm scripts. The Scorer is a built artifact the gateway imports — like compiled CSS, not a new browser.

Win for this lesson. A real starter dataset is already on disk: datasets/smoke-queries.jsonl (48 coding-agent prompts). Validate it below. Do not spend credits yet.

What “train the router” actually means

AIand already hosts Flash, Qwen, Motif, GLM, K3. Those weights are not yours to train. The hop spec’s Scorer is a tiny in-process classifier: complexity bin + P(success) per eligible model, then cheapest-above-bar. Hop spec, Solution.

Think fixtures.json → mock review → Playwright against the real API → a dist/ file the app loads. Three paid-or-local jobs, then a JSON artifact:

1. queries unpaid JSONL of prompts
→
2. teacher Motif (then GLM) guesses bins + silver P(success)
→
3. gold Flash + measured trio actually answer, short
→
4. fit local math → scorer.json

Teacher labels from the query alone are silver — a guess, not gold. Dense success matrices in the literature are built by running candidates (teacher-labeling note; RouteLLM: Ong et al., 2024). This CLI writes silver, then gold-where-present, and must not calibrate on silver. Stories 33–34.

The file format (you already know this)

JSON Lines: one JSON object per line, newline-separated, not one giant array. The train CLI accepts prompt or OpenAI-style messages (train.py _messages). 

{"prompt": "Rename tmp to userCount in src/stats.ts.", "phase": "edit", "hint_bin": "trivial"}

phase and hint_bin are for you to keep the set balanced. Extra keys are ignored by the reader. Today the teacher job stamps phase=plan on silver rows — a shortcut, not something you need to fix this session.

48 rows is a starter, not the $100 ceiling (teacher ≤1000, sparse gold ≤200 × Flash+trio). Public SWE-bench Verified is a gate, not this smoke corpus (bootstrap-datasets).

Skill: prove the file is valid JSONL

Paste or edit. Click validate. You want 48 valid rows and a mix of hint_bin / phase.

What you will run later (not now)

PowerShell, venv on, from the repo root. Opt-in is required so pytest cannot spend:

$env:AIAND_TRAIN="1"
python -m aiand_router.train teacher --queries datasets/smoke-queries.jsonl --out data/silver.jsonl --limit 5
python -m aiand_router.train gold --queries datasets/smoke-queries.jsonl --out data/gold.jsonl --limit 5
python -m aiand_router.train fit --gold data/gold.jsonl --silver data/silver.jsonl --out data/scorer.json

--limit 5 is a wallet-safe rehearsal. Teacher talks to Motif-3, then GLM on hard/low-confidence rows (≤25% escalate). Gold talks to Flash + Qwen + Kimi K2.7 Code + V4 Pro, max_tokens=64, never K3. Fit is local — no provider. Cache hits are free. Job refuses if AIAND_TRAIN is unset. README, Trained path.

Skip this block until you are ready to spend. Next lesson we run --limit 5 together and read one silver row. Ask before raising the limit toward 200.
